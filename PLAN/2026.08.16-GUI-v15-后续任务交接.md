## 3. 当前 GUI 能力

GUI 使用纯标准库 tkinter/ttk,没有 WebView、前端框架或第三方运行时 UI 依赖。正式程序名为 fakenet-GUI.exe。

主窗口包含五个标签页:

1. 基础配置
2. 出站策略
3. 监听器
4. 自定义响应
5. 实时日志

已实现的重要行为:

- Yes/No 与 True/False 用户选项使用复选框,但写入 INI 时保持各自精确字面量。
- 出站策略总开关映射 Disabled/DomainAllowList,不是普通布尔值。
- 出站任务区使用多域名列表、私网分析主机开关、公网 IPv4 规则表和单目标进程重定向。
- 目标 PE 路径变化后异步计算并写回 SHA-256。
- DNSListener 和 DomainEgressRelay 等策略拓扑自动、幂等补齐。
- 系统自动管理监听器只读显示,可“重新生成”。
- 主窗口只显示一行校验摘要;完整错误在独立、可缩放窗口显示。
- 字段错误显示在控件下方;所有已知字段保留鼠标悬停和键盘焦点提示。
- 导入配置直接绑定原文件;恢复默认配置经确认后覆盖当前绑定文件。
- FakeNet 运行期间锁定编辑、导入、恢复、保存和再次启动;退出后自动解锁。
- GUI 使用 Windows 命名 mutex 保证单实例。
- fakenet-gui.spec 设置 upx=False 并使用 PyInstaller 原生 splash。
- GUI 自身日志和 GUI 启动的核心日志都写入相应 exe 同级 Logs 目录,但不混写。
- 实时日志只跟随当前 GUI 启动的核心实例,完整追加;暂停只停止自动滚动。

当前明确未实现的功能:

1. 私网导向时允许多个真实联网域名。
2. 一个配置支持多个进程重定向目标。
3. 仅按进程名匹配并支持正则。
4. 仅按 PID 匹配。

这些功能涉及 egresspolicy.py、processredirect.py 或 Windows 数据面,不能只改 GUI。收到此类需求时,必须先升版安全方案、说明核心影响面并重新审计。

## 4. v14 为什么不能通过验收

用户导出的 v14 证据位于:

    dist\Logs-GUI-v14\20260816-144731\

results.tsv 把 A1-A9 全部标为 PASS,但同目录 fakenet.log 明确记录:

    FakeNet-NG terminated with an error
    UnboundLocalError: cannot access local variable 'fn_addr'
    Stopping...
    FakeNet-NG exiting: rc=1

根因:

1. 核心 Fakenet.start() 只在 DivertTraffic=Yes 分支初始化 fn_addr,却在所有启用监听器路径中无条件使用它。DivertTraffic=No 且存在启用监听器时会崩溃。
2. 旧 VM runner 的 A6 只检查进程曾短暂出现,A8 只检查进程后来消失。它没有拒绝 traceback、异常终止或非零退出,所以把快速崩溃误判为启动成功和优雅停止。
3. 旧 runner 声称生成“单 RawTCPListener”,但 ConfigModel.new_config() 自带两个启用 ProxyListener 段,旧脚本没有删除,实际配置包含三个启用监听器。

结论:不能只看 results.tsv。任何后续验收都必须同时审计同次 fakenet.log。

## 14. 不可破坏的核心合同

### 14.1 INI 布尔语义

三套格式不得混用:

    Enabled              -> True/False
    fuzzy、DivertTraffic -> Yes/No
    UseSSL               -> 精确 Yes
    Hidden               -> 字面 True

此外:

- 值中的百分号写为双百分号。
- 每个监听器段显式写 Enabled。
- FakeNet 和 Diverter 段名大小写敏感。
- 写出 INI 注释只能使用 ASCII。

### 14.2 配置编码

保存编码必须等于读入编码,并保留 GBK、UTF-8 BOM/UTF-8-SIG 和原始 CRLF/LF。新建配置使用 ASCII、CRLF、无 BOM。

### 14.3 Fail-closed

以下情况必须拒绝启动:

- VM 检测不确定。
- 判定为物理机。
- 已存在 fakenet.exe。
- 配置路径含引号。
- 配置路径含控制字符。
- 配置路径以反斜杠结尾。

不得为方便测试放宽这些门禁。

### 14.4 双源真相

GUI 的 schema.py/validator.py 自持核心约束副本,与 egresspolicy.py、processredirect.py、windows.py 保持一致。锚定测试覆盖:

    资源元组:(5, 65536, 256, 32, 128, 16, 300, 1048576)
    443 约束
    三布尔语义
    TCP 锁
    监听器类清单漂移

核心约束变化时,先让漂移测试识别差异,再同步 GUI 副本。
