3. `069fdd0` — Windows `socketpair()` 环回握手被 diverter 截获→`accept()` 永久阻塞（py-spy 线程栈实锤）。
4. `2b04465` — 从未 serve 的 HTTP server 调 `shutdown()` 死锁 + `SSLWrapper.__del__` GC 破坏性清理竞态（第 23 轮 ENOENT）。

每个缺陷均有 VM 实证取证（套接字创建时间戳/线程栈/日志指纹）与 Wine 回归；门禁候选沿革 r35→r42 全程按 AUD-P05-002 作废旧证据。
