## 失败链还原（discovery100-06 sst-018，B2 restart）

run-01 healthy → restart RPC → 内嵌 stop 的 `full_audit_diff`（settle 30s）持续差异 → stop failed 'environment restoration audit failed' → restart 拒绝 → run 终态 failed、配置 config_in_use 卡死、执行器 finally IPC 拆卸因受控停服失败而未恢复环境。

证据链（vm-recovery-audit.jsonl / vm-incident-evidence.json / 基线原件）：

1. 审计三份采样的差异**仅为 listen_ports**；`_normalize` 已过滤连接行，归一化后真实差异**只有一行**：`UDP 192.168.204.233:52496`（基线有、审计时无，属主 pid 1624 外部进程）。
2. incident-02/03 的 baseline_diff 里出现的 `fakenetng-mcp.exe diagnostic-task` 是**失败后 incident 收集器自己的诊断子进程**（process_tree: pid 4756，创建于 managed 退出后 144s，incident 采集时段），属事后证据自观察伪影；审计采样时刻并不存在（进程段比对亦有控制客户端豁免）。
3. `closed_udp_changes` 只豁免"运行自身 ETW trace 完全观察到的关闭"，外部属主 socket 无从观察 → 拒绝 → 审计必败，且**随机触发**（任何外部临时 UDP 在基线稳定存在≥3×1.5s 后于运行期间关闭）。

## 产品修复（源提交 96c36b2 → 4354da9 → fe0fd17，三层递进）

1. **外部属主归因**（96c36b2）：`endpoint_attribution.foreign_udp_owner_changes`——严格证明拒绝后，对"仅 listen_ports 差异且全部为 UDP 行"逐行按**原始行 PID** 归因：属主在端点 trace 起始进程快照中存在（先于运行）且不在基线 managed 集 → 环境性变化，记录 attributed 证据并放行；属主运行期间才出现、属基线托管进程、混合/非UDP差异、任何歧义 → 拒绝。无端口阈值、无进程名白名单。接线于 `full_audit_diff`（decisions 落盘 `.attribution.json`）。
2. **窗口范围修正**（4354da9）：原实现沿用 closed_udp_changes 的"采样窗口必须落在 trace 内"，而恢复重审计必然晚于 trace 结束 → 永久拒绝。外部归因仅依赖 trace 起始快照 → 放宽为仅要求基线窗口起点不早于 trace 起点。
3. **start-only 证明降级**（fe0fd17）：首次 stop 失败会把端点观察留在未完成态（`udp.etl.part` 孤儿、无 end marker），`audit_proof` 永远抛 "observation is incomplete" 且异常路径跳过外部归因 → 恢复永久楔死。新增 `EndpointObservation.start_proof()`（仅读 trace-start 证据），外部归因接受 start-only 证明（显式存在但不完整的 end marker 仍拒绝），审计接线在严格证明失败时降级尝试。

测试：test_endpoint_attribution 46 通过（新增外部归因接受/拒绝矩阵、恢复重审计窗口、start-only、接线降级）；本地 test/mcp 722 passed（Windows 门在 Docker 构建内全绿）。

## 恢复楔死的部署处置（现场方法论，非产品变更）

- 部署 runner 前置要求 clean stopped，与 failed 楔死态互锁；受控停服与 Restart-Service 均被 failed 协调器拒绝。
- SCM failure 动作为 RESTART/30s：强杀进程后换装窗口被自动重启抢占（两次树核对失败）。
- `deploy-tools/manual_recovery_swap.py`：host-only 服务 ZIP → guest 逐字节验证 stage（197成员）→ 挂起 SCM 自动重启 → 强停 → 换装 → 恢复动作 → 启动，**由新产品的启动恢复自行完成挂起清理**（真实恢复条件下验证修复）。fe0fd17 部署后 run 4de848a7 恢复收敛 stopped-clean，IPC 环境恢复（environment_restored=true），卡死配置删除。
- 备份：`C:\Program Files\FakeNet-NG-MCP-backup-manual-*` 保留于 VM。
