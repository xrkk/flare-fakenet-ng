## 1. 背景与目标

原版 FakeNet-NG 通过 INI 配置文件驱动,所有配置(含本 fork 新增的全部 `External*` 出站策略功能)都靠手写 INI。本方案新增一个图形配置工具 **fakenet-config**:可视化编辑全部配置项(原版 + fork 新增)、实时校验(尊重代码中的硬约束)、并从界面直接启动 FakeNet-NG。

**非目标**:不做运行时监控(日志流/连接/PCAP 状态);不修改 fakenet 核心逻辑(纯增量);不替代 PowerShell 启动器的完整安全流程(见 §10 差异说明)。

## 3. 现状调研摘要(方案依据,均已核实到源码行号)

### 3.1 配置系统
- INI,`ConfigParser` 全默认参数:分隔符 `=`/`:` 皆可(项目惯用冒号 `Key: Value`);键读出即小写;**段名大小写敏感**(`[FakeNet]`/`[Diverter]` 精确匹配,其余任意段名一律视为监听器)。
- 加载链:`fakenet/fakenet.py:72-113 parse_config()` 分桶(仅收录 `Enabled` 为真的监听器段)→ `expand_listeners()`(端口区间 `60000-60010` 展开为 `<段名_端口>` 多实例)→ 注入 `ipaddr/configdir/networkmode` → 各监听器收普通 dict。
- 路径语义:`Custom:` 相对 CWD/主配置目录(`qualify_file_path`);`WebRoot`/`FTPRoot`/CA 等走 `abs_config_path`(CWD → exe 目录或 fakenet 包父目录)。

### 3.2 布尔三套语义(GUI 写文件必须精确产出对应字面量)
1. `Enabled`(监听器段):`configparser.getboolean()`,仅 `1/yes/true/on/0/no/false/off`;**键缺失即崩溃**。
2. fuzzy 布尔(`is_set`/`is_clear`,fnconfig.py:66-70):真词 `yes/on/true/enable/enabled`,假词 `no/off/false/disable/disabled`,**不含 1/0**。
3. 精确字符串比较:`DivertTraffic` 只认小写比较 `'yes'`;`UseSSL` **精确匹配大写 `'Yes'`**(各监听器);`Hidden` 只认 `.lower()=='true'`。

规范化策略:GUI 统一产出——`Enabled`→`True/False`,fuzzy/`DivertTraffic`→`Yes/No`,`UseSSL`→`Yes/No`,`Hidden`→`True/False`。

### 3.3 硬约束清单(校验器与锁定的依据)
- **始终硬锁死**(`egresspolicy.py:430-475`):`ExternalAllowedTCPPorts` 恰为 `{443}`;`ExternalVerifyTLSSNI/ExternalBlockExternalIPv6/ExternalBlockQUIC` 必须 Yes;8 项资源限额元组必须等于 `(5, 65536, 256, 32, 128, 16, 300, 1048576)`;进程重定向协议必须 `TCP`(`processredirect.py:682-684`)。
- **条件锁**:takeover 启用时域名仅 `api.deepseek.com`、`ExternalNonAllowedAction=Divert`、两个 DNS 段 `ResponseA == ExternalTakeoverIPv4`(egresspolicy.py:495-504、windows.py:608-613)。
- **范围/格式**:TTL 1–300、探测端口≤64、探测超时 100–5000、DnsTimeout 1–30、RelayPort 1–65535;域名 IDNA;IPv4 按 RFC1918/全球单播分类;SHA256 为 64 hex 且须与实盘文件一致;进程镜像路径须绝对盘符、禁 UNC/ADS/通配。
- **跨段拓扑**(DomainAllowList 模式,windows.py:585-617):恰 1 个 `DomainEgressRelay` 监听器(TCP,Port=`ExternalRelayPort`)+ 恰 2 个 53 端口 `DNSListener`(一 UDP 一 TCP)+ 其他监听器不得占用中继端口。
- **互斥**:`ProcessWhiteList`/`ProcessBlackList`、`HostWhiteList`/`HostBlackList`(监听器级与 Diverter 级);`RedirectAllTraffic` 开启时 `DefaultTCP/UDPListener` 必须引用已存在段名。
- **平台**:全部 `External*` 策略 Windows-only;Linux 对 Reviewed IPv4 规则/进程重定向直接拒绝。

### 3.4 打包与构建
- `fakenet.spec`:onefile、`console=True`、`uac_admin=True`、WinDivert 驱动随包;tkinter 是在 Analysis 后用旧式 `TOC` 减法剔除(PyInstaller 6 已移除该语法)。
- CI(`.github/workflows/build.yaml`):windows-2022 + Python 3.10 + 最新 PyInstaller;release zip 内 `fakenet.exe` 与 `fakenet\configs\`(模板来源)、`fakenet\defaultFiles\` 同级。
- `setup.py` entry_points:`fakenet=fakenet.fakenet:main`。
- 项目现有 ctypes 先例(`winutil.py` adapter 模式、`IsUserAnAdmin`)与 PowerShell 子进程先例(`windows.py:624-629`,`-NoProfile -NonInteractive -ExecutionPolicy Bypass` + `CREATE_NO_WINDOW`);`ShellExecuteW runas` 为新引入。

### 3.5 其他已核实的坑
- 值中裸 `%` 会被 BasicInterpolation 解析崩溃,必须写 `%%`。
- fakenet 读 INI 不带 encoding → 按系统区域编码(中文 Windows 为 GBK);GUI 写 UTF-8 中文注释会产生乱码,含非 ASCII 的值有损坏风险。
- `Proxy` 段的 `Listeners:` 键是死代码(ProxyListener 实际嗅探全部监听器)。
- 系统注入键 `ipaddr/configdir/networkmode` 不应出现在 INI。

## 5. 模块设计

### 5.1 schema.py — 声明式字段目录
每字段一条记录:`key / 中文标签 / 控件类型 / 默认值 / 约束(min/max/枚举/regex/IP类别) / 锁定规则ID / 所属分组 / 提示`。控件类型枚举:`bool_yesno`、`bool_truefalse`、`int`、`string`、`enum`、`stringlist`、`portlist`、`portspec`(区间感知)、`ipv4`、`path_file`/`path_dir`(带浏览按钮)、`hex64`、`text`(多行,ExecuteCmd)。

内容:
- `[Diverter]` 全字段分 6 组:基础(NetworkMode/DebugLevel 值域 16 标签)、抓包(DumpPackets 双 PCAP/前缀)、DNS与网关修复(FixGateway/FixDNS/ModifyLocalDNS/StopDNSService)、重定向与黑名单(RedirectAllTraffic 联动、BlackListPortsTCP/UDP、**BlackListIDsICMP[Windows-only idlist,v0.2 补 P5:代码实现于 diverterbase.py:577,1350-1354,但 default.ini:158 仅注释样例]**、名单互斥)、Linux 专用 3 项、出站策略四个子组(域名放行/私网接管/公网 IPv4 放行/进程重定向,含全部 `External*` 25+ 项)。
- 锁定规则 ID 化:`LOCK_TCP_PORTS_443`、`LOCK_BOOL_YES×3`、`LOCK_RESOURCE_TUPLE`、`LOCK_PR_PROTOCOL_TCP`;条件锁 `COND_TAKEOVER_*`(仅 DomainAllowList + takeover 时生效)。**`External*` 全部字段仅在 `ExternalAccessPolicy=DomainAllowList` 时参与校验,Disabled 时灰显不校验**(与源码一致)。
- 监听器:共有 9 字段(Enabled/Port/Protocol/Listener 可选=匿名段/Hidden/两对互斥名单/ExecuteCmd)+ 10 类特有字段目录(DNS/HTTP/FTP/IRC/TFTP/Raw/SMTP/POP/Proxy/DomainEgressRelay),含陷阱标注(UseSSL 精确 'Yes'、Proxy `Listeners:` 仅文档、Hidden 只认 'true')。**盲区键补充(v0.2,P5,均为"代码实现但模板缺省/注释"键)**:DNS 的 `ResponseA` 按"字面 IPv4 ∪ 特殊枚举 `GetFirstNonLoopback`/`GetHostByName`"双态定义(DNSListener.py:224,232);`cert_dir`(UseSSL 动态证书目录,默认 `configs/temp_certs`,HTTPListener.py:217)列为高级已知字段。
- **值保真规则(v0.2,P5/F5)**:`\r\n`、`\t` 等转义序列是配置值的一部分(FTP Banner、自定义响应样例均使用),GUI 编辑时按字面处理,不得解释、转换或规范化。
- 自定义响应:已知字段目录(HTTP 型:HttpURIs/HttpHosts 至少其一、响应体三选一、ContentType 限制;Raw 型:Tcp/Udp 前缀四选一)。**平铺展示全部已知字段,不做交互式变体切换**(评估轮砍掉的简化)。
- 排除系统注入键(ipaddr/configdir/networkmode),不渲染。

### 5.2 configmodel.py — 保真读写
- **读**:裸 `ConfigParser` 读**全部**段(含 `Enabled=No` 的——`parse_config()` 会丢弃它们,编辑器必须保留);按文件顺序存 OrderedDict;schema 外的未知键进"额外键"区,**不丢任何数据**。
  - **读取编码策略(v0.1 新增,U2)**:以 `utf-8-sig` 优先尝试,解码失败回退系统区域编码(与 fakenet 读取语义一致)——防止 UTF-8 BOM 文件首段名混入 BOM 字符、或 GBK/UTF-8 混存文件被读错后在保存时静默损坏。非 ASCII 值一律交校验器出警告(§5.3)。
- **写**(严守 §3.2/§3.5):冒号风格;段名 `[FakeNet]`/`[Diverter]` 精确大小写;布尔按 §3.2 规范化字面量;`%`→`%%`;每监听器段必写 `Enabled`;无重复段/键;文件头 **ASCII 英文**注释。
  - **ASCII 责任边界(v0.1 消解 R2)**:GUI **新写入/编辑产生的值**保证 ASCII;**源文件既有的非 ASCII 值原样保真保留**(不转码、不丢弃,校验器警告)。"输出 ASCII-only"断言仅适用于 ASCII 源文件;非 ASCII 源文件的断言是"保真保留"(见 §6)。
- **写出编码规范(v0.2,P2,四项)**:① **保存编码 = 读取时探测到的源编码**(GBK 源写 GBK、utf-8-sig 源写 utf-8-sig),落实"非 ASCII 值不转码";② **BOM 原样保留**(utf-8-sig 读入的文件写回仍带 BOM)——带 BOM 文件在中文系统会被 fakenet 以 GBK 读取、BOM 三字节混入首段名导致解析错乱,故校验器对 BOM 文件出警告;③ **新建文件缺省**:纯 ASCII、无 BOM;④ **行尾风格保真**:CRLF/LF 按源文件保留,新建文件用 CRLF(Windows 平台)。
- **保存前外部修改防护(v0.1 新增,R1)**:保存时比对文件 mtime 与载入时快照,不一致则提示"文件已被外部修改",由用户选择覆盖或重新载入,防并发编辑丢失。
- 端口区间原样保留 + "将展开为 N 个实例"预览。

### 5.3 validator.py — 规则引擎
输入配置模型,输出 `(error|warning, 段/字段定位, 消息)` 列表;**errors 非空 → 禁用启动按钮**;字段变更 debounce 重跑;状态栏"⚠N 错误 / M 警告"。

规则(errors,按 §3.3 全量实现):
1. 段名与 `[fakenet]`/`[diverter]` 大小写不敏感相等但非精确匹配 → 错误(否则 fakenet 当监听器段崩溃)。
2. 监听器段必备 `Enabled/Port/Protocol`;`Protocol∈{TCP,UDP}`;`Listener` 值为合法类名(大小写敏感);端口可解析 1–65535;端口展开实例彼此及与既有段名无冲突;**展开后启用段之间 (Protocol, Port) 去重(v0.2,P4)——同协议同端口双绑定时 fakenet 运行时 bind 失败即 `sys.exit(1)` 整体退出(实证 fakenet.py:266-274 为 fail-fast,非"记错继续"),必须在启动前拦截**。
3. 名单互斥(监听器级 + Diverter 级);`RedirectAllTraffic` 开 → `DefaultTCP/UDPListener` 引用存在段名;`DivertTraffic=Yes` → `NetworkMode` 必填。
4. DomainAllowList 模式:`DivertTraffic` 必须 'yes';拓扑硬约束(§3.3 跨段拓扑);13 项硬锁死字段复核(UI 锁定为第一道,校验器复核为第二道——防"外部改文件再载入")。
5. takeover:IPv4 RFC1918 可用/非本地/≠DNS;TTL/探测端口/超时范围;域名条件锁;DNS ResponseA 联动。
6. Reviewed IPv4 规则:三段式语法/全球单播/≤32 条 16 IP/存在即非空/无重复/不与本地冲突。
7. 进程重定向:开启时 5 项全必填;协议 TCP;路径绝对盘符且存在;SHA256 64hex;A 全球单播、B RFC1918、A≠B、不与 DNS/takeover 冲突。
8. 通用:域名 IDNA 合法;`ExternalDnsServer=Auto` 或可用单播 IPv4;`__*__` 占位符 → "请填入实际值";ExecuteCmd 占位符(`{pid}` 等)合法。

规则(warnings,不阻断):Webroot/Custom/FTPRoot/TFTPRoot/CA 等路径不存在;DumpPackets 开而未设前缀;非 ASCII 值("fakenet 按系统区域编码读取,可能乱码");Linux 专用项配在 Windows 场景等。

**「一键补齐必需监听器」按钮**:DomainAllowList 模式缺拓扑时可用,按 `domain_allowlist_windows.ini` 自动创建缺失的 relay + 2×DNS 段,并在 takeover 启用时把 DNS 段 `ResponseA` 填为接管 IP(已有值不动)。

### 5.5 launcher.py — 启动流程
1. 校验通过(0 错误)→ 未保存则提示保存(另存为默认 exe 旁 `configs\`,不可写退用户目录);**启动前 fakenet.exe 进程探测(v0.2,P3)**:`tasklist /FI "IMAGENAME eq fakenet.exe"` 发现已运行实例即拒绝启动——PS 启动器有独占锁文件(`Start-DomainAllowList.ps1:199-210`,FileShare::None),GUI 以进程探测近似替代,防双 WinDivert 句柄 + 双重 DNS 改写的未定义行为(ShellExecuteW 不返回进程句柄,GUI 不做运行期管理)。
2. **VM 检测**(沿用 `windows.py:624` PowerShell 先例,`Start-*.ps1:31` 同款正则 `virtual|vmware|virtualbox|kvm|qemu|hyper-v|xen|parallels` 匹配 `Win32_ComputerSystem` Manufacturer/Model),**后台线程执行,不得冻结 UI 线程(v0.2,P7:CIM 查询秒级耗时)**。**不确定态裁决(v0.2,采纳审计 F1):fail-closed**——VM→放行;物理机→拒绝并红色警告;**不确定(PS 失败/超时)→ 拒绝启动,提示改用 PowerShell 启动器或修复 WMI/PowerShell 后重试**。与全仓 fail-closed 姿态(Start-*.ps1 `$ErrorActionPreference='Stop'`、PolicyConfigError 体系)对齐;WMI 损坏场景下 PS 启动器同样失败(其 720-724 行同样依赖 CIM),不产生 GUI 可用性倒退。
3. 定位目标:冻结 → 同目录 `fakenet.exe`;缺失时弹出路径选择,允许手工指定(复用 path_file 控件);**持久化到 `%APPDATA%\fakenet-config\settings.json`,持久化路径无效时回落同目录探测并提示(v0.2,P11,修正 v0.1"优先于同目录探测"的过强表述)**;**dev → `[sys.executable, '-m', 'fakenet.fakenet']` 且 cwd=仓库根(v0.2,P1 修正:直接跑 `fakenet/fakenet.py` 脚本不可用——fakenet.py:33 `from fakenet import listeners` 在脚本模式(sys.path[0]=包目录)下 ModuleNotFoundError,且开发机若曾 `pip install .` 会静默 import site-packages 旧副本造成版本错配;`-m` 形式与 `Start-DomainAllowList.ps1:286` 项目先例一致)**。**配置路径含引号/控制字符/尾反斜杠时拒绝启动**(防 ShellExecuteW 参数注入;v0.2,P9 补尾反斜杠:CommandLineToArgvW 语义下"尾反斜杠+闭引号"会把引号转义为字面量)。
4. UAC 提权:`ctypes.windll.shell32.ShellExecuteW(0,'runas',exe,'-c "<绝对路径>"',dir,SW_SHOWNORMAL)`(按 `winutil.py` 风格声明 argtypes);**检查返回值(v0.2,P6):≤32 为失败,`SE_ERR_ACCESSDENIED(5)`=用户取消 UAC——失败/取消时不得提示"已启动"**;成功后提示"已启动;后续配置修改不影响运行中实例(fakenet 启动时一次性读取配置)",fakenet 控制台独立运行,用户在其中 Ctrl+C 停止。
5. **Linux:不提供启动**,提示手动命令 **`python -m fakenet.fakenet -c <ini>`**(v0.2,P1:脚本直跑形式不可用,理由同第 3 条;评估轮砍掉 best-effort 终端探测)。

5. **无语义扩张**:不修改 schema 字段、validator、configmodel、launcher 和核心;不增加折叠组/搜索/新状态机。部署包目标升 v7,manifest plan v1.6。
